# Hospital Analytics Dashboard

## Overview
This project is a **Hospital Analytics Dashboard** created using Microsoft Power BI. It visualizes key performance indicators and demographic data related to hospital operations, including patient demographics, admission types, medical conditions, and billing information.

## Features
- **Total Patients**: Displays the total number of patients treated.
- **Total Billing Amount**: Visualizes the cumulative billing amount.
- **Average Length of Stay**: A gauge chart shows the average patient stay duration.
- **Patients by Gender**: A pie chart represents the distribution of male and female patients.
- **Patients Age by Gender**: A bar chart visualizing age distribution for male and female patients.
- **Patients by Admission Type**: A bar chart comparing admission types (Elective, Urgent, Emergency).
- **Patients with Insurance**: A pie chart displaying insurance provider statistics.
- **Patients by Medical Condition**: A tile chart categorizing patients based on medical conditions.
- **Patients Discharge Trends**: A line chart depicting patient discharge trends by gender.

## Tools Used
- **Power BI**: For creating interactive visualizations and dashboards.
- **Data Sources**: 
  - Admission Data
  - Billing Information
  - Patient Information

## Key Insights
1. Gender distribution of patients is almost equal.
2. Age group data reveals higher patient counts in specific age brackets.
3. Admission types and medical conditions provide insights into hospital operations.
4. Insurance provider analysis shows an almost balanced distribution among major providers.
